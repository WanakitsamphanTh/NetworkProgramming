# Network Programming Project
## Description
This is the final project for our network class. We built a simple HTTP server and hosted a web board for our classmates.
Each comment is altered with fun random gimmicks or emojis to irritate the users.
## Feature
- Message alternations with emojis after every sentence. (Sentence boundary detected by a full stop)
- Real time message (we used an intuitive approach instead of any frameworks)
